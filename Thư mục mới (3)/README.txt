HUONG DAN CHAY CHUONG TRINH QUAN LY TRUNG TAM NGOAI NGU

1. Giai nen thu muc QuanLyTrungTamNgoaiNgu.
2. Mo thu muc nay bang Visual Studio Code.
3. Dam bao tat ca cac file .py nam cung mot thu muc.
4. Mo file main.py.
5. Bam Run Python File hoac chay lenh:
   python main.py

CAC FILE VA CHUC NANG:
- main.py: Menu va dieu khien chuong trinh.
- du_lieu.py: Danh sach hoc vien, bang gia khoa hoc, duong dan file TXT.
- tien_ich.py: Nhap du lieu, kiem tra so nguyen, dinh dang tien.
- hoc_vien.py: Them, hien thi, cap nhat, xoa va tim hoc vien theo ma.
- tim_kiem_sap_xep.py: Tim kiem va sap xep hoc vien.
- dang_ky.py: Dang ky khoa hoc va tinh hoc phi.
- thong_ke.py: Thong ke hoc vien va hoc phi.
- quan_ly_file.py: Doc va luu du lieu hoc vien vao hoc_vien.txt.

Luu y: Khi chay chuong trinh, file hoc_vien.txt se duoc tao trong cung thu muc
khi ban luu du lieu lan dau tien.
